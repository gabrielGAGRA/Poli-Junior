# Exported Flows

Recommended place for Python files generated from Agent Builder when deploying only ChatKit/Vercel.

Before using a generated flow in runtime, apply the required fixes documented in:
- AJUSTES_FLUXO_GERADO.md

Default NDados filename accepted by runtime:
- fluxo-NDados.py

You can also override lookup with env vars:
- LOCAL_FLOWS_DIR
- LOCAL_FLOW_NDADOS_FILE
